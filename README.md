# India Export Commodity Analysis

A data analytics project analyzing India's top 15 export commodities by value, comparing full calendar years **2024 and 2025 (Jan–Dec)**. Built as an end-to-end pipeline: **PostgreSQL → Python → Power BI**.

## 📌 Problem Statement

India's export basket includes commodities that behave very differently year to year — some grow steadily, some spike and fall, and some quietly gain or lose market share. Growth alone can be misleading (a low base can inflate it), consistency alone can hide strong absolute performers, and market share captures competitiveness that growth figures miss.

This project analyzes the **top 15 commodities by export value** (chosen this way specifically to avoid selection bias) to examine growth, stability, and market-share performance together — rather than relying on any single metric — and to identify where these measures agree and where they diverge.

## 🔧 Tech Stack

- **PostgreSQL** — structured data storage and SQL-based aggregation
- **Python** (pandas, numpy, matplotlib) via **Jupyter Notebook** — statistical analysis, sector grouping, forecasting
- **Power BI** — interactive dashboard for reporting

## 📊 Data Source

Monthly commodity-wise export data for India's top 15 commodities by value, sourced from the **Ministry of Commerce's TradeStat portal** (tradestat.commerce.gov.in). Since the portal's own cumulative figures follow India's fiscal year (Apr–Mar), the monthly values were used to independently build a calendar-year (Jan–Dec) view for this analysis.

## 🚀 How to Run

1. **Data collection** (optional — cleaned data is already provided) — `SCRAPER/tradestat_scraper.py` is a Selenium script that automates form submissions on the TradeStat portal (15 commodities × 12 months = 180 combinations) and compiles the results into a single Excel file. *Note: raw commodity names use `/` (e.g. "MOTOR VEHICLE/CARS") as they appear on the source website; these were converted to `-` (e.g. "MOTOR VEHICLE-CARS") during cleaning, matching what's used in the SQL and Python analysis.*
2. **Database setup** — run `SQL/sqlfinal.sql` in PostgreSQL to create the `exports_v2` table and view the SQL-layer query results (Q1, Q2, Q3, Q4, Q6).
3. **Load data** — open `PYTHON/export_final.ipynb` and run the cells to load `DATA/Export_Data_Top15_Clean.csv` into PostgreSQL and run the Python-layer analysis (Q5, Q7–Q10).
4. **Dashboard** — open `POWERBI/EXPORTFINAL.pbix` in Power BI Desktop. It connects to the PostgreSQL `exports_v2` table plus the CSV exports generated by the notebook (`composite_ranking.csv`, `volatility_scores.csv`, `sector_performance.csv`, `forecast_top3.csv`).

## 📈 Key Findings

- Overall export value grew only **+1.44%** (2024 → 2025) — a modest headline figure that masks sharp commodity-level divergence.
- **Telecom Instruments** had the strongest YoY growth (+53.61%) and the largest market share gain, but was also the **most volatile** commodity in the study.
- **Petroleum Products** remained the largest export commodity by value in both years despite the steepest decline (−22.22%) and the biggest market share loss.
- **Marine Products** — never a top performer on any single raw metric — ranked **#1** on a composite score combining growth, stability, and market share, highlighting that no single metric captures "best performance" on its own.
- Sector-wise, **Electronics** was the strongest performer (+37.06%) and **Energy** the weakest (−22.22%).
